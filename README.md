# La Casita - Landing Page 🏡

Landing page desarrollada en **HTML y CSS** para promocionar *La Casita*, un alojamiento turístico en Villa La Angostura, Patagonia Argentina.  
El sitio presenta información sobre la propiedad, sus comodidades, ubicación y medios de contacto.

## 🌐 Demo
La página está desplegada en Vercel:  
👉 [https://lacasita-web.vercel.app/](https://lacasita-web.vercel.app/)

## 🛠️ Tecnologías utilizadas
- **HTML5** para la estructura del contenidogit push origin main

- **CSS3** para estilos y diseño responsivo
- **Vercel** para hosting y despliegue
